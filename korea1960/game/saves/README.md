# 검토용 저장 파일 (저장 형식 5)

게임의 타이틀 화면 또는 기록실 → **저장 파일 불러오기**로 연다. 현재 진행을 바꾸므로 필요하면 먼저 내보낸다.

| 파일 | 시점 | 내용 |
| --- | --- | --- |
| 1964_start_governing.json | 1964-01 | 헌정 경로·가상 선거·취임 직후. 행동점수 3을 그대로 남겨 건설·법률·집권 연합·정책·외교를 바로 시험할 수 있다. |
| 1965_market_and_laws.json | 1965-01 | 소시민을 집권 연합에 넣고 언론 자유 보장을 발의한 뒤 1년. 학교·관개·건설 부문·봉제 공장을 대기열에 올린 상태에서 시장·건물·법률·이해집단 화면을 본다. |
| 1966_regional_edicts.json | 1966-03 | 지역 시책 2개(전북 곡창 증산 지도·부산 수출 공업 우선 지역)와 강원 탄광·부산 항만 착공 이후. |
| 1973_policy_choices.json | 1973-01 | 같은 캠페인을 1973년까지 진행한 상태. 중화학공업 역사 앵커 직후. |

모든 값은 게임 실행으로 만든 가상 수치다. `node tools/make_sample_saves.mjs`로 다시 만든다.
이전 판(저장 형식 1~4)의 저장은 경제 구조가 달라 이 판에서 불러올 수 없다. `tests/fixtures/`의 이전 형식 파일은 그 거부를 검사하는 데 쓴다.
