# 검토용 저장 파일 (저장 형식 4)

게임의 타이틀 화면 또는 기록실 → **저장 파일 불러오기**로 연다. 현재 진행을 바꾸므로 필요하면 먼저 내보낸다.

| 파일 | 시점 | 내용 |
| --- | --- | --- |
| 1964_start_governing.json | 1964-01 | 헌정 경로·가상 선거·취임 직후. 행동점수 3을 그대로 남겨 정책·법안·사업·외교·자문을 바로 시험할 수 있다. |
| 1964_bills_and_projects.json | 1964-09 | 언론 자유 법안 표결, 전남 농촌 보건 거점 준공, 가상 법제 자문위원, 농업 기술 보급과 일본 정례 대화 이후. |
| 1966_regional_edicts.json | 1966-03 | 지역 시책 3개(전북 곡창 증산 지도·강원 산림 보호구역·부산 수출 공업 우선 지역)와 고유 사업 2건(전북 곡창 경지 정리·강원 탄광 기계화) 준공 이후. 지도의 ‘지형·자원’과 권역 카드를 시험할 수 있다. |
| 1973_policy_choices.json | 1973-01 | 같은 캠페인을 1973년까지 진행한 상태. 중화학공업 역사 앵커 직후. |

모든 값은 게임 실행으로 만든 가상 수치다. `node tools/make_sample_saves.mjs`로 다시 만든다.
제작 패키지 v1이 만든 버전 1 저장은 `example/saves/`에 그대로 있으며, 불러오면 형식 4로 자동 변환된다(`tests/fixtures/`에도 같은 사본).
