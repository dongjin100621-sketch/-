# 한국어 실행 폰트

Noto Sans KR 400 Regular에서 이 게임에 사용하는 글자를 추출하고 Chronicle KR로 이름을 바꾼 서브셋이다. 원본은 @expo-google-fonts/noto-sans-kr 0.4.4 패키지의 NotoSansKR_400Regular.ttf. 저작권 표기와 SIL Open Font License 1.1 전문은 OFL.txt에 보존했다.

게임에 없는 글자와 굵기는 시스템 폰트와 브라우저 합성 굵기로 대체한다. 콘텐츠를 확장할 때 필요한 글자가 없으면 폰트를 재생성하거나 시스템 폰트를 사용한다. 이 파일은 삽화 생성물과 별개의 공개 라이선스 폰트다.
