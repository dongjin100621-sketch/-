# 클로드에 처음 전달할 제작 프롬프트

당신은 한국어 역사 정치·경제 시뮬레이션을 구현하는 게임 개발자다. 첨부한 제작 패키지의 문서와 데이터, 실행 가능한 예시를 읽고 **《대한민국 1960: 선택의 연대기》**를 완성도 높은 데스크톱·모바일 웹 게임으로 확장해라. 참조 대상은 Steam의 《For the Fatherland: Chronicle of Park Chung-hee》지만, 제공된 독자 기획·수식·데이터·미술을 기반으로 개발한다. 원작의 내부 구현을 안다고 가정하거나 원작 소스·대사·화면·이미지를 복제하지 말 것.

## 먼저 할 일

1. `00_START_HERE.md`, `docs/GAME_DESIGN.md`, `docs/SIMULATION_RULES.md`, `docs/DATA_CONTRACT.md`, `docs/SOURCES_AND_HISTORY.md`, `docs/ART_DIRECTION.md`를 읽어라.
2. `data/game.json`의 레코드 수, ID 참조, 사건 조건, 엔딩 우선순위를 확인해라. 분리된 JSON은 읽기 편의를 위한 복사본이다. 정본은 game.json이고 변경 시 분리본을 다시 생성해라.
3. `example/engine.mjs`, `example/app.mjs`, `example/style.css`, `example/index.html`과 `tests/engine.test.mjs`를 분석해라. 동작 중인 계산 엔진과 저장 스키마를 보존하면서 발전시켜라. 기존 예시를 이름만 바꾼 새 프로젝트로 덮어쓰지 말 것.
4. 파일을 직접 읽을 수 없다면 읽은 척하지 말고 `CLAUDE_CONTEXT.md`를 우선 사용한 뒤 필요한 파일을 정확한 이름으로 요청해라.

## 필수 게임 경험

* 1960년 1월~1979년 12월, 월 단위 캠페인. 플레이어는 박정희라는 역사적 출발점에 있다. 1960년에 대통령 권한을 주지 않는다.
* 초반 관찰·정책 준비, 헌정 경로/군정 경로의 추상적 분기, 가상 선거와 취임, 국정 운영, 권한 이양 또는 기간 종료의 전체 흐름을 유지한다.
* 매월 사건 선택과 행동점수 3. 재정, 부채, 성장, 물가, 교육, 농업, 산업, 기반 시설, 복지, 자유, 정당성, 환경, 지역 균형, 지지도가 상호작용한다.
* 정책 24개, 사업 16개, 권역 10개, 외교 상대 6종, 가상 자문위원 6명, 엔딩 12개를 실제 게임에 연결한다. 사건 수는 CONTENT_INDEX.md를 기준으로 모두 로드한다.
* 법안은 발의 후 5~7개월의 심의 과정을 거쳐 가결·부결된다. 정당성·지지도·가상 의석이 표결에 반영된다.
* 건설은 자금과 슬롯을 사용하고 일정 개월 후 효과가 발동한다. 즉시 완공·중복 구매·무료 행동·턴 건너뛰기 악용을 막는다.
* 같은 상태를 공유하는 상황판·정책·의회·사업·재정·외교·내각·기록실을 만든다. 각 버튼에는 동작과 비활성 사유가 있어야 한다.
* 결정 직전 비용·즉시 효과·지연 효과를 읽을 수 있고 결정 후 무엇이 변했는지 기록된다. 숫자만 바뀌고 아무 설명도 없는 UI를 만들지 않는다.
* 시드 난수, 저장/불러오기, 저장 JSON 내보내기/가져오기, 버전 검사, 손상된 저장 거부, 연대기, 엔딩 평가를 유지한다.

## 이미지와 UI

제공된 cover/cabinet/industry/civic WebP를 각 맥락에 쓰고 원본 PNG는 보존해라. 깊은 청록·황동·아이보리의 문서 기반 디자인, 명료한 한국어, 읽기 쉬운 카드와 표를 사용한다. `assets/ui/tokens.json`과 SVG 아이콘을 활용한다. 생성 이미지에 제목이나 버튼을 굽지 말고 HTML 텍스트로 렌더링한다. 좁은 화면에서도 선택지·하단 행동·저장 버튼이 잘리지 않아야 한다. 키보드 초점과 최소 44px 터치 대상을 갖춘다. 외부 이미지 URL과 폰트 CDN에 의존하지 않는다.

## 역사와 표현

역사적 사건은 sourceIds를 연결하고 실제 역사와 가상 반응을 구분해라. 모든 경제 수치는 가상 모형 값으로 표시한다. 가상 자문위원을 실제 장관이라고 쓰지 않는다. 성장과 인권을 독립된 축으로 평가한다. 군사정변·정치 폭력은 헌정적 결과와 제도적 비용만 추상화하고 실제 작전·암살·폭력의 절차를 구현하지 않는다. 시민과 노동자의 희생을 보상 수단으로 사용하지 않는다. 실제 사건과 달라진 분기에서 역사적 사건을 그대로 강제하지 않는다.

## 개발 방식

외부 AI API, 계정 로그인, 유료 서비스 없이 실행해야 한다. 예시 엔진은 의존성 없는 JavaScript ES module이다. 완성 프로젝트는 TypeScript + Vite로 구조화해도 되지만, 제공 엔진의 동작과 데이터 계약을 먼저 유지한다. 현재 작업 환경에 맞는 설치 버전을 확인하고 잠금 파일을 함께 제출한다. 단일 HTML 예시를 요구하지 않은 거대한 서버 구조로 바꾸지 않는다. 최종 산출물에는 더블클릭 실행 가능한 HTML도 포함한다.

작업을 계획 설명에서 끝내지 말고 파일을 실제로 수정하고 실행해라. 예시 엔진·콘텐츠 검증 테스트를 실행한 뒤 화면을 확인하고, 캠페인 끝까지 자동 진행하여 교착·NaN·무한 반복·빈 사건·미완공 사업·깨진 엔딩이 없는지 검사한다. 새로운 기능은 필요한 계산 테스트와 함께 검증한다. 저작권 있는 원작 데이터를 구하려고 중단하지 말고 패키지의 창작 자료로 완성해라.

한 번에 처리하기 어렵다면 `prompts/STAGED_WORKFLOW.md`의 단계로 진행하고 각 단계마다 실행 가능한 상태·변경 파일·검증 결과·남은 문제·다음 지시를 CHECKPOINT.md에 남겨라. 상용 수준의 모든 확장을 이미 구현했다고 과장하지 않는다.

## 최종 제출

실행 가능한 전체 소스 ZIP, 바로 열 수 있는 HTML, 실행 방법, 데이터 수정 위치, 저장 호환성 설명, 실제 수행한 검증 결과를 제공해라. 초기 단계부터 정책이 작동하는 척하는 그림만 보여 주지 말고 캠페인을 실제로 진행할 수 있어야 한다. 사용자가 별도 설명을 붙이지 않아도 이어서 개발할 수 있도록 작업 상태를 문서화해라.

지금 패키지를 읽고 기존 예시를 분석한 뒤 첫 구현 단계를 시작해라.

# 대한민국 1960: 선택의 연대기 · 제작 설계

## 목표 경험

플레이어는 1960년의 박정희라는 역사적 출발점에서 공적 역할과 통치 경로를 선택한다. 후반에는 한 국가의 생산, 재정, 시민적 자유, 생활, 지역 균형을 함께 관리한다. 정책을 누르면 끝나는 화면이 아니라 자원 지출, 시간 지연, 의회 심의, 사업 준공, 시민의 반응이 연결되어야 한다. 특정 정치적 평가를 정답으로 강요하지 않으며 권리 침해의 비용은 명시한다.

캠페인은 1960년 1월~1979년 12월, 1턴=1개월, 총 240턴이다. 샘플은 240턴을 끝까지 진행할 수 있는 계산·진행 기준이며 상용 게임 완성본은 아니다. 고유 제목과 에셋을 사용한다. 참조 게임의 모든 화면·세부 기능을 동일하게 복제하는 것이 목표는 아니다.

## 권한과 단계

| 단계 | 시기·조건 | 허용 행동 |
| --- | --- | --- |
| prelude | 1960-01~1961-04 | 자료 검토, 정책 준비, 공개적 원칙 확인. 국정 지표는 관찰 |
| civilian | 1961-05 헌정·퇴역 분기~1963년 선거 | 민간 경로의 준비. 국가 재정·건설 집행 불가 |
| transition | 1961-05 군정 분기~1963년 선거 | 경제 정책·건설·예산 등 집행 가능, 정규 의회 법안은 민정 이후 |
| elected | 1963-10 가상 선거에서 당선~12월 | 당선인 준비. 전면 국정 집행은 취임 이벤트 이후 |
| governing | 1963-12 취임 선택 이후 | 모든 정책·입법·사업·외교·내각 행동 |

초반의 영향력은 공약·연합 준비를 추상화한다. 군사 작전 준비를 의미하지 않는다. 1963년 가상 선거는 절차를 압축한 설계로 실제 득표나 선거 운동을 재현하지 않는다. 패배하면 평화적 이양 엔딩으로 이어진다. 1967년·1971년 이후는 48개월 주기의 가상 정기 선거로 단순화한다. 유신 경로에서는 자유·정당성의 지속 비용을 치르며 정기 선거가 중단된다.

## 월별 순서

1. 해당 월의 사건 큐를 먼저 해결한다. 선택 효과와 예약된 지연 효과는 연대기에 남긴다.
2. 매월 행동점수 3. 정책, 법안 발의, 건설 착수, 외교, 자문 교체, 사전 준비가 각 1점이다. 월 예산 배분 수정은 무료다.
3. 월 종료 시 수입·지출·이자→지표 변화→정책/자문 지속 효과→건설 진척→법안 진척→지연 효과→지지도 갱신→정기 선거·위기·엔딩을 처리한다.
4. 자동 저장 후 다음 월의 사건을 구성한다. 동일한 시드와 동일한 입력은 동일 결과를 만든다. 종료 상태에서는 어떤 행동도 상태를 바꾸지 않는다.

## 재정과 성장

자세한 수식은 `SIMULATION_RULES.md`와 `example/engine.mjs`를 따른다. 돈의 단위는 재정점이다. 가상 생산 지수는 1960년=100으로 시작한다. 세금은 고정된 간단한 세입 함수를 사용한다. 국고가 음수면 부족분만큼 부채가 늘고, 금융위기 기준을 넘으면 엔딩이다. 정책 비용은 즉시 지출과 월 유지비로 나뉜다. 건설은 착수비를 한 번 지출하고, 준공 이후 유지비와 수입이 붙는다.

모든 예산 배분은 합계 100이어야 한다. 산업, 농업, 교육, 생활, 기반 시설, 안보의 여섯 항목이며 배분 총액은 월별 가용 재정 범위 내의 모형 지출로 계산한다. 0으로 배분하면 관련 역량이 자연 감쇠할 수 있다. 세금·물가·대출을 별도 복잡한 거시모형으로 확장하는 작업은 후속 범위다.

## 정책·입법

정책 24종. 시행된 정책은 중복 시행할 수 없다. 잠금 연도와 권한 단계를 검사한다. `requiresBill`인 정책은 의회에서 법안을 발의하고 5~7개월의 심의를 거친다. 법안 상태는 발의→상임위→법제 검토→본회의→가결/부결이다. 실제 국회의 과거 법안 절차나 소요기간을 재현한 수치가 아니라 게임 규칙이다.

통과 확률은 가상 의석 점유율·정당성·사회 안정으로 정해지며 가결/부결은 시드 난수로 결정한다. 표결에 성공하면 정책이 한 번만 시행되고 월 유지비가 붙는다. 부결 법안은 다시 발의할 수 있다. 심의 중인 법안을 중복 발의할 수 없다. 청탁·불법 강요 등 실행 수단은 넣지 않는다.

## 건설·권역

사업 16종, 권역 10개, 권역당 슬롯 4개. 같은 사업을 같은 권역에 중복 건설할 수 없다. 사업 착수 뒤 지정 개월이 지나면 완공 효과를 한 번 적용한다. 권역의 개발도도 증가한다. 전국 지표와 권역 개발도는 별개의 값이다. UI 지도는 도식이고 당시 행정 경계가 아니다. 생산 시설에는 환경 비용이 있고 교육·보건·환경 사업은 다른 지표를 개선한다.

## 외교·자문

외교 상대 6종은 미국·일본·북한 외에 서유럽·비동맹권·국제기구 묶음을 포함한다. 회담, 기술 교류, 인도적 협력의 세 가지 공통 행동이 관계·자원에 영향을 준다. 전쟁 전술이나 현실 정권 전복 절차를 다루지 않는다. 자문위원 6명은 모두 가상 인물이며 동시에 2명까지 임명한다. 자문마다 지속 효과가 다르다.

## 사건과 역사 분기

역사 앵커 18종과 가상 정책 사건, 사전 준비 사건을 제공한다. 정확한 개수는 CONTENT_INDEX.md를 따른다. 날짜가 정해진 사건도 선택 효과는 창작이다. 통치 경로가 달라지면 당시 역사 문맥을 자료집에 남기고 현재 세계의 사건으로 단정하지 않는다. 사건 조건 DSL은 `phaseIn`, 지표 비교, flag 비교, 연도 제한을 지원한다. 선택지는 3개이며 자원 부족 시 비활성 이유를 보여 준다. 모든 사건에는 최소 한 개의 무료 선택이 있다. 선택 비용은 행동점수와 별도로 처리한다.

## 엔딩

12개 엔딩. 긴급 실패 엔딩을 먼저 판정하고, 명시적 퇴임·권한 이양, 기간 종료 시 조건에 따른 평가 순으로 처리한다. 복수 조건에 해당하면 priority가 높은 엔딩을 택한다. 성장과 자유·생활·환경의 추이를 따로 표시하고, 연대기에 중요한 선택·법안·준공·선거 결과를 보존한다. 단일 점수로 희생이나 권리 침해를 지우지 않는다.

## MVP 완료 기준

새 게임→초기 사건→사전 준비→통치 경로 분기→1963년 선거→취임→월별 정책·입법·사업·외교→정기 선거 또는 권위주의 비용→1979년 종료/조기 엔딩을 실제로 진행한다. 모든 화면의 숫자는 같은 상태에서 읽고 버튼은 상태를 바꾼다. 저장 파일을 내보내 다시 불러오면 난수 상태와 미해결 사건·법안·사업이 보존된다. 모든 자료를 로컬로 제공하여 이미지나 폰트의 외부 링크가 끊겨도 실행된다.

## 후속 확장

예산 세목과 세율, 독립 통화정책, 계층별 소득 분포, 지역 인구 이동, 동적 헌법 조문, 장관의 상호작용, 실제 통계 캠페인, 사운드와 접근성 튜토리얼은 별도 확장 항목이다. 샘플에 이미 구현됐다고 소개하지 않는다. 핵 개발·테러·암살·쿠데타 작전의 실행 세부는 확장 범위에 포함하지 않는다.

# 모형 수식과 처리 계약

수치의 의미: 모두 게임 설계용 가상 값. 생산 지수는 1960년=100, 돈은 재정점, 시민적 자유와 국가 역량은 0~100이다. 실제 GDP·물가·실업률을 재현한 추계가 아니다. 이 문서와 충돌하면 현재의 `example/engine.mjs`를 먼저 확인하고, 코드와 문서를 함께 수정한다.

## 시간과 행동

`turn=0`은 1960-01, `turn=239`는 1979-12, `turn=240`은 종료된 상태다. 매월 AP=3. 행동은 원본 상태를 직접 수정하지 않고 복제본을 만들며, 성공할 때만 새 상태를 반환한다. 실패하면 원본 상태를 그대로 반환한다.

해당 월의 사건이 남아 있으면 사건 선택 외의 게임 행동을 할 수 없다. 월 종료는 AP를 쓰지 않는다. 모든 AP를 반드시 소비할 필요는 없다. 사건 선택은 AP를 사용하지 않지만 명시된 국고 비용은 지불해야 한다.

## 월 재정

* 월 수입 = 11 + 생산 지수 × 0.035 + 준공 시설의 월 수입 합
* 기본 지출 = 10 + 생산 지수 × 0.014
* 월 이자 = 부채 × 0.003
* 월 유지비 = 시행 정책의 유지비 + 준공 시설 유지비 + 자문위원 수 × 0.15
* 월 수지 = 수입 - 기본 지출 - 월 이자 - 월 유지비
* 다음 국고 = 현재 국고 + 월 수지. 음수인 경우 부족분을 부채에 더하고 국고를 0으로 만든다.

월 배분은 지출 총액을 새로 만들지 않고 여섯 역량의 성장 방향을 정한다. 분야 역량 변화 = (해당 배분율 - 12) × 0.006. 합계가 100이 아닌 배분, 음수, 숫자가 아닌 입력은 거부한다. 초반 권한이 없는 단계의 배분은 국가 상황을 관찰하기 위한 고정 기본값이다.

## 생산과 사회 지표

월 생산 증가율 r은 다음 식을 -0.01~0.012로 제한한다.

`r = 0.0025 + 산업×0.00003 + 교육×0.000012 + 기반시설×0.000018 - max(0, 물가-12)×0.00015 - 실업률×0.00004`

다음 생산 = 현재 생산 × (1+r).

* 물가 변화 = (8-물가)×0.012 + max(0, 부채-220)×0.0001
* 실업률 변화 = (12-실업률)×0.012 - 산업×0.0003
* 환경 변화 = -산업×0.00035
* 안정 변화 = (정당성-안정)×0.008 + (생활수준-45)×0.0008
* 정당성 변화 = (자유-50)×0.0008 + (생활수준-45)×0.0005
* 분배 균형 변화 = (생활수준-분배균형)×0.002
* 권위주의 분기에서는 매월 자유 -0.3, 정당성 -0.1을 추가한다.

정책·자문위원의 지속 효과는 집행 권한이 있는 transition/governing 단계에서만 합산한다. 기본 재정은 모든 단계에서 국가 관찰 모형으로 진행한다. 지표별 상·하한은 data/metrics.json이다.

## 지지도·선거·표결

매월 각 집단의 목표 지지도는 해당 집단이 중시하는 지표 세 개의 평균이다. 다음 지지도 = 현재 + (목표-현재)×0.025. 사건의 즉시 지지 변화는 이 계산 전에 적용된다. 종합 지지도는 faction.weight의 가중 평균이며 가중치 합은 1이다.

1963년의 가상 당선 확률(%) = `35 + 준비 영향력×0.18 + (정당성-45)×0.25 + (종합지지도-45)×0.15`, 범위 25~90%. 당선하면 elected 상태, 12월 취임 사건 이후 governing. 패배하면 평화로운 권한 이양 엔딩이다. 실제 득표나 선거일정 전체를 재현하지 않는다.

1967년 11월부터 48개월마다 가상 정기 선거를 적용한다. 실제 1967년·1971년 선거 날짜와 구별한다. 득표 지표 = `종합지지도×0.65 + 정당성×0.35 + 균등난수(-6,+6)`. 45 미만이면 평화적 이양 엔딩, 그 외 가상 의석 점유율을 결과/100으로 갱신한다. 권위주의 분기에서는 이 정기 선거가 중단된다.

법안 심의 기간은 시드 난수로 5~7개월. 통과 확률은 `0.15 + 의석점유율×0.75 + (정당성-50)×0.002 + (안정-50)×0.001`을 0.15~0.95로 제한한다. 0~1 난수가 확률보다 작으면 가결. 시행비는 발의 때 지불하고 부결되어도 환급하지 않는다. 법안이 가결된 이후부터 정책 유지비가 발생한다.

## 사업·지연 효과

사업 착수 시 비용과 AP 1을 지불한다. 착수한 월의 종료부터 remaining을 1씩 줄인다. 0이면 준공, 완공 효과를 정확히 한 번 적용한다. 다음 달부터 준공 시설의 수입과 유지비를 재정에 반영한다. 권역별 슬롯은 진행 중과 준공 사업을 합쳐 4개이며 같은 권역의 같은 사업은 한 번만 가능하다.

사건 선택에서 N개월 지연 효과를 예약하면 `due=현재 turn+N`으로 저장한다. 해당 월 종료 경계가 due에 도달하면 효과를 한 번 적용하고 예약에서 제거한다. 일반 사건과 지연 효과가 겹쳐도 지연 효과는 별도 연대기 기록을 남긴다.

## 시드와 종료

난수는 상태에 저장되는 32비트 xorshift다. 큐 생성·법안 기간·표결·선거에만 엔진이 사용한다. UI는 난수를 소비하지 않는다. 저장 파일은 rng와 미해결 큐를 보존한다.

부채>=700, 정당성<=3, 자유<=3을 우선순위로 검사한다. 명시적인 퇴임·이양 선택은 해당 엔딩을 기록한다. 240개월 종료 시 조건을 만족하는 가장 높은 우선순위의 평가 엔딩을 고른다. `explicit` 엔딩은 기간 종료 판정에 자동 선택되지 않는다. 종료 후 dispatch는 항상 실패하며 상태를 변경하지 않는다.

## 밸런스의 한계

이 모형은 설명 가능한 제작 기준이다. 실제 인과효과를 추정한 거시경제 모형이나 정치 예측 모형이 아니다. 반복 사건·정책 조합의 체감 난이도, 엔딩의 자연 플레이 도달률, 장기 재정과 무한 지출 가능성은 후속 플레이테스트에서 조정해야 한다. 저장 버전과 데이터 버전이 바뀌면 마이그레이션 또는 명시적인 비호환 안내를 추가한다.

# 데이터 계약과 저장 구조

`data/game.json`이 정본이다. 분리 JSON 12개(밸런스 규칙 `balance.json` 포함)는 같은 레코드를 읽기 편하게 제공하는 사본이며 엔진이 따로 병합하지 않는다. 변경 후 `python3 tools/validate_content.py --sync`로 사본을 갱신하고 검증한다. 선택지·정책·사업·국가·권역·출처 ID는 저장 호환성을 위해 임의로 바꾸지 않는다.

## 사건 조건과 선택

조건 배열의 모든 항목을 만족해야 표시된다. 지원 조건은 `{phaseIn:[...]}`, `{flag:'won1963',eq:true}`, `{yearGte:1963}`, `{yearLte:1979}`, `{metric:'liberty',gte:60,lte:100}`이다. 날짜는 YYYY-MM 형식. 날짜가 없는 사건은 현재 단계와 재등장 대기 개월 수에 따라 추첨한다. 정해진 달에 조건이 성립하지 않는 역사 사건은 자동 강제하지 않는다.

선택 필드: `id`, `label`, `effects`(metric ID→수치), `factionEffects`(faction ID→수치), `relations`(country ID→수치), `influence`, `setFlags`, `phase`, `delay:{months,effects,text}`, `special:'firstElection'`, `ending`. 새로운 특수 동작을 데이터 문자열만으로 실행하지 않는다. 미등록 함수나 eval을 허용하지 않는다.

사건 art는 cover/cabinet/industry/civic 중 하나. kind는 historical_anchor 또는 fictional_system. 역사 앵커의 sourceIds는 반드시 유효 출처를 가리킨다. 사건 본문의 실제 역사 문장과 선택 이후의 대체역사 결과를 분리한다.

## 엔진 인터페이스

`createState(data, seed)` → 신규 상태.

`dispatch(state, data, action)` → `{ok:true,state}` 또는 `{ok:false,state:original,error}`. 원본을 변경하지 않는다.

행동: choose(choiceId), prepare, policy(id), project(id,regionId), budget(budget), diplomacy(countryId,mode), adviser(id), repay(amount), endMonth. 외교 mode는 talk/technology/humanitarian.

`exportSave(state)` → JSON 문자열. `importSave(raw,data)` → 검증된 상태 또는 Error. 두 함수는 저장 버전·게임/데이터 버전·수치 범위·ID·배열 크기·일부 구조적 일관성을 검사한다. 파일은 2MB 이하. 손상된 입력을 상태에 부분 반영하지 않는다. 서명된 경쟁 게임 저장이 아니므로 치트 방지나 서버 권위 검증을 보증하지 않는다.

## 저장 상태

format=KOREA1960_SAVE, version=1. state에는 version,gameId,dataVersion,turn,rng,phase,ap,influence,seats,stats,support,relations,budget,policies,bills,projects,advisers,flags,queue,lastEvents,delayed,history,log,ending,lastFinance,visited가 들어간다.

법안 상태: introduced/committee/legal_review/plenary/passed/failed. 사업 상태: building/complete. 대기 사건은 콘텐츠 ID 배열이며 결과 문구를 저장하지 않는다. 엔딩은 ID와 발생 턴으로 복원하므로 외부 JSON의 임의 제목을 신뢰하지 않는다. UI는 불러온 텍스트와 출처 설명을 HTML escape한다.

## 변경·마이그레이션

동일 콘텐츠 ID의 표시 문구만 수정하는 경우 저장 버전을 유지할 수 있다. 지표의 의미·사건 분기·ID·상태 구조를 바꾸면 dataVersion 또는 save version을 올리고, 구버전 파일을 안전하게 거부하거나 순수 변환 함수를 제공한다. 호환성 경고를 지우기 위해 버전 검사를 임의로 제거하지 않는다. 현재 예시는 다른 버전의 저장을 거부한다.

TypeScript 참고 타입은 data/types.d.ts에 있다. 스키마의 기본 형태는 data/game.schema.json, 실제 참조·의미 검증은 tools/validate_content.py와 테스트가 담당한다. 동작하는 정본 데이터를 검증하기 위한 스키마이지 모든 가상 확장 필드를 이미 지원한다는 뜻이 아니다.

# 화면·이미지 지침

깊은 청록, 낡은 황동, 아이보리 문서, 절제된 주홍의 기록물 분위기. 지표와 결정이 중심이고 일러스트는 여백과 맥락을 준다. 과도한 군사 영웅화나 선전 포스터 구도를 피한다. 텍스트는 생성 이미지에 새기지 않고 HTML로 렌더링한다.

기준 화면: 1440×900. 왼쪽 내비게이션 210px, 중앙 작업 영역, 오른쪽 월별 브리핑. 1100px 이하에서는 오른쪽 패널을 아래로 보내고, 760px 이하에서는 내비게이션을 가로 스크롤로 전환한다. iPhone의 좁은 화면에서도 지표와 선택지가 잘리지 않아야 한다. 터치 대상 44px 이상, 초점 테두리, 색 이외의 증감 기호와 단위 표기를 둔다.

| 화면 | 핵심 내용 | 실제 행동 |
| --- | --- | --- |
| 상황판 | 날짜·권한·행동점수·생산/물가/정당성/자유·추이·지지도 | 월 종료·사전 준비 |
| 정책 | 분야 필터·시행비·유지비·효과·잠금 이유 | 시행 또는 법안 발의 |
| 의회 | 의석 점유율·심의 단계·표결 결과 | 법안 발의 |
| 사업 | 권역 도식·슬롯·사업 기간·완공 효과 | 권역 선택·착수 |
| 재정 | 국고·부채·수입·지출·배분 합계 | 합계 100 예산 적용 |
| 외교 | 국가별 관계·대화/교류/협력 비용 | 외교 행동 |
| 내각 | 가상 인물·효과·임명 여부 | 임명/해임 |
| 기록실 | 연대기·역사/가상 구분·출처·수치 설명 | 저장 내보내기/불러오기 |

PNG 4장은 1672×941 생성 원본, WebP 4장은 실행용 파일이다. 표지의 인물은 실존 인물 초상으로 식별하지 않는 뒷모습이며 이미지의 도시 풍경은 가상이다. UI 아이콘 12개와 권역 도식은 원본 SVG다. 자문위원 초상은 이니셜 UI를 사용한다. 새 초상·음악·음성은 납품 범위에 포함되지 않으며 필요하다면 별도 제작한다.

표지 원본은 일반적 시대 분위기이며 특정 연도의 정확한 스카이라인 증거로 쓰지 않는다. 원작의 로고·Steam 표지·스크린샷은 에셋으로 배포하지 않는다. `assets/manifest.json`, `assets/ART_PROMPTS.md`, `RIGHTS_AND_ATTRIBUTION.md`를 함께 유지한다.

# 역사 검증과 참조 범위

확인 기준일: 2026-11-10. 아래 자료는 날짜와 제한된 사건 맥락을 확인하기 위한 것이다. 실제 게임을 구매·실행하거나 내부 코드를 분석한 결과가 아니다. 참조 게임의 공개 상점 설명과 사용자가 올린 검색 결과 이미지를 기준으로, 동일한 장르의 독자적 구현을 위한 자료를 작성했다.

참조 게임에서 공개적으로 확인한 범위는 1960년 박정희 시점의 시작, 정치·경제 관리, 의회·헌법의 역할, 주요 역사 분기와 복수 엔딩이다. 이 패키지의 월별 수식·이벤트·자문 인물·지도·이미지·엔딩 조건은 자체 설계다. 원작의 전체 데이터나 내부 규칙을 재현했다고 주장하지 않는다.

## 표현 기준

* historical_anchor: 실제 발생한 사건을 한두 문장으로 요약하고 아래 sourceIds를 연결한다. 플레이어의 선택지와 수치 효과는 창작이다.
* fictional_system: 가상 정책 상황. 특정 인물의 실제 발언이나 실제로 있었던 개별 사건이라고 소개하지 않는다.
* 대체역사: 선택 후의 통치 경로·선거 결과·정책 효과는 가상이다. 이미 달라진 정치체제에 실제 사건의 인과관계를 강제로 적용하지 않는다.
* 모든 경제·사회·외교 수치는 모형 값이다. 시작 시점의 물가·실업·생산·지지도가 실제 통계라는 주장은 하지 않는다.
* 1960년부터 대통령 권한을 주지 않는다. 초반은 관찰과 사전 준비다. 군정 경로와 헌정 경로의 권한이 다르다.
* 성장 성과와 인권 침해는 별개의 평가축이다. 경제 성과로 권리 침해를 상쇄하는 단일 도덕 점수를 만들지 않는다.
* 군사정변은 결과와 헌정적 비용만 다룬다. 실제 작전·병력·폭력·은폐의 실행 절차를 구현하지 않는다.
* 노동·민주화 사건의 희생자를 존중한다. 고통을 보상 수단이나 오락용 장면으로 사용하지 않는다.
* 생성 삽화와 가상 자문위원은 실제 역사 사진·실제 관료로 표기하지 않는다.

# 개발 인수 메모

이 프로젝트는 플랫폼 계정·API 키·AI 추론·데이터베이스 없이 실행하는 로컬 예시다. 클로드는 추론 호출을 게임의 매턴 진행에 붙일 필요가 없다. 고정 콘텐츠·순수 엔진으로 결과를 재현하고, 필요한 창작 확장은 개발 단계에서 작성한다.

## 명령

* `node --test tests/engine.test.mjs` : 핵심 엔진 검증
* `python3 tools/validate_content.py` : 정본/분리본·참조·무료 선택지·이미지 누락 검사
* `python3 tools/validate_content.py --sync` : 정본에서 분리본 재생성 후 검사
* `python3 tools/build_standalone.py` : 단일 HTML 재생성
* `python3 tools/serve.py` : 127.0.0.1에서 분리 소스 실행
* `node tools/make_sample_saves.mjs` : 검토용 저장 두 개 재생성

테스트에는 최근 Node의 내장 node:test만 필요하고 별도 npm 설치는 없다. Python 도구도 표준 라이브러리만 사용한다. 이미지를 다시 압축하려면 별도 이미지 도구가 필요하지만 기본 실행·빌드에는 필요 없다. 개발 환경은 Node 24.22.1 / Python 3.12.14에서 확인했다. 사용자의 런타임 버전이 다르면 현재 검증 결과를 그대로 적용한다고 가정하지 않는다.

## 파일 경계

engine.mjs는 DOM·localStorage·네트워크를 사용하지 않는다. app.mjs는 입력을 dispatch로 보내고 반환된 상태만 그린다. UI 안에서 비용이나 결과를 따로 계산해 상태를 수정하지 않는다. 단, `visited`만 화면 방문 기록으로 UI가 갱신한다. __GAME_DEBUG__는 검토용으로 상태 복사본과 dispatch를 노출하며 경쟁·서비스 배포에서는 제거할 수 있다.

빌더는 엔진의 export와 앱의 import를 제거해 같은 내용을 인라인 module로 묶고 이미지·아이콘·JSON을 데이터로 내장한다. HTML을 직접 고치면 분리 소스에 반영되지 않는다. 수정은 engine/app/style/game.json에서 하고 다시 빌드한다.

## 다음 개발 우선순위

1. 실제 브라우저의 첫 플레이와 좁은 화면의 가독성을 확인한다.
2. 초반과 후반을 포함한 사용자 플레이테스트로 진행 속도와 난이도를 조정한다.
3. 정책별 지연 효과와 집단 반응을 UI에서 더 비교하기 쉽게 만든다.
4. TypeScript로 옮길 경우 기존 엔진과 동일 입력·동일 결과 회귀 검사를 유지한다.
5. 실제 통계나 동적 헌법·복잡한 통화정책을 추가한다면 별도 설계·출처·저장 마이그레이션을 만든다.

## 알려진 단순화

초반 국가 지표는 관찰 모형이며 플레이어가 조작하는 예산이 아니다. 1963년 선거와 취임은 사건으로 압축한다. 후속 정기 선거는 역사적 일정과 달리 48개월 주기로 단순화한다. 권역 특성은 설명용이며 생산성 배율로 반영하지 않는다. 자문위원은 이니셜로 표시한다. 배경음·음성·전투·지도 전선·실제 정당별 의석 모델은 없다. 모든 엔딩의 조건 검증은 실제 자연 플레이에서 고르게 등장한다는 뜻이 아니다.
