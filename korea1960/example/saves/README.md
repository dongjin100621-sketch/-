# 검토용 저장 파일

기록실→저장 JSON 가져오기에서 불러온다. 현재 진행을 바꾸므로 필요하면 먼저 내보낸다.

* 1964_governing.json: 헌정 경로와 가상 선거를 거쳐 취임한 직후. 언론 자유 법안 심의, 전남 보건 거점 건설, 가상 법제 자문위원이 포함된다.
* 1973_policy_choices.json: 같은 캠페인을 1973년 1월까지 진행한 상태. 중화학공업 역사 앵커와 여러 정책·사업을 검토할 수 있다.

모든 값은 게임 실행으로 생성한 가상 수치다. 실제 역사 저장 자료가 아니다. `node tools/make_sample_saves.mjs`로 재생성한다.
