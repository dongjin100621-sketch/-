# 화면·이미지 지침

깊은 청록, 낡은 황동, 아이보리 문서, 절제된 주홍의 기록물 분위기. 지표와 결정이 중심이고 일러스트는 여백과 맥락을 준다. 과도한 군사 영웅화나 선전 포스터 구도를 피한다. 텍스트는 생성 이미지에 새기지 않고 HTML로 렌더링한다.

기준 화면: 1440×900. 왼쪽 내비게이션 210px, 중앙 작업 영역, 오른쪽 월별 브리핑. 1100px 이하에서는 오른쪽 패널을 아래로 보내고, 760px 이하에서는 내비게이션을 가로 스크롤로 전환한다. iPhone의 좁은 화면에서도 지표와 선택지가 잘리지 않아야 한다. 터치 대상 44px 이상, 초점 테두리, 색 이외의 증감 기호와 단위 표기를 둔다.

| 화면 | 핵심 내용 | 실제 행동 |
| --- | --- | --- |
| 상황판 | 날짜·권한·행동점수·생산/물가/정당성/자유·추이·지지도 | 월 종료·사전 준비 |
| 정책 | 분야 필터·시행비·유지비·효과·잠금 이유 | 시행 또는 법안 발의 |
| 의회 | 의석 점유율·심의 단계·표결 결과 | 법안 발의 |
| 사업 | 권역 도식·슬롯·사업 기간·완공 효과 | 권역 선택·착수 |
| 재정 | 국고·부채·수입·지출·배분 합계 | 합계 100 예산 적용 |
| 외교 | 국가별 관계·대화/교류/협력 비용 | 외교 행동 |
| 내각 | 가상 인물·효과·임명 여부 | 임명/해임 |
| 기록실 | 연대기·역사/가상 구분·출처·수치 설명 | 저장 내보내기/불러오기 |

PNG 4장은 1672×941 생성 원본, WebP 4장은 실행용 파일이다. 표지의 인물은 실존 인물 초상으로 식별하지 않는 뒷모습이며 이미지의 도시 풍경은 가상이다. UI 아이콘 12개와 권역 도식은 원본 SVG다. 자문위원 초상은 이니셜 UI를 사용한다. 새 초상·음악·음성은 납품 범위에 포함되지 않으며 필요하다면 별도 제작한다.

표지 원본은 일반적 시대 분위기이며 특정 연도의 정확한 스카이라인 증거로 쓰지 않는다. 원작의 로고·Steam 표지·스크린샷은 에셋으로 배포하지 않는다. `assets/manifest.json`, `assets/ART_PROMPTS.md`, `RIGHTS_AND_ATTRIBUTION.md`를 함께 유지한다.
