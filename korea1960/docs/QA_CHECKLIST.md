# 인수·검수 기준

- [ ] 새 게임에서 1960년 1월과 군인 신분, 국정 권한 제한이 표시된다.
- [ ] 사건을 해결하기 전 일반 행동이나 월 종료를 할 수 없다.
- [ ] 사전 준비는 영향력과 AP만 사용하고 국가 예산 집행 권한을 부여하지 않는다.
- [ ] 1961년 경로, 1963년 선거·취임, 1972년 제도 분기가 저장에 남는다.
- [ ] 정책·법안·사업의 연도·권한·AP·비용·중복을 검사한다.
- [ ] 법안은 5~7개월 뒤 한 번만 표결되고 가결 시 한 번만 정책 효과를 적용한다.
- [ ] 사업은 지정 개월 뒤 한 번 완공된다. 슬롯은 진행 중·완공을 모두 센다.
- [ ] 예산 합계 100 외 입력은 거부한다. 음수·NaN·문자열 값은 거부한다.
- [ ] 외교·내각은 비용·AP가 실제로 줄고 동일 상태를 공유한다.
- [ ] 월별 수입·지출·이자 내역과 국고 부족분의 부채 전환이 일치한다.
- [ ] 지표가 범위를 벗어나지 않고 NaN·Infinity가 생기지 않는다.
- [ ] 시드와 입력이 같으면 선거·사건·표결 결과도 같다.
- [ ] 저장→복원 이후 아직 남은 사건·난수·법안·사업·지연 효과가 같다.
- [ ] 잘못된 버전, 미등록 ID, 과도한 크기, 잘못된 자료형의 저장은 거부한다.
- [ ] 엔딩 이후 행동이 상태를 변경하지 않는다. 새 게임으로 정상 초기화된다.
- [ ] 1960~1979 전체 진행이 가능하고 모든 엔딩 조건을 별도 상태로 검증한다.
- [ ] 기록실에서 역사 출처와 가상 수치·인물 라벨을 확인할 수 있다.
- [ ] Chrome 계열 데스크톱, 390px 모바일 뷰포트에서 가로 잘림·콘솔 오류가 없다.
