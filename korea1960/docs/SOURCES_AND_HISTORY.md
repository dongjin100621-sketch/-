# 역사 검증과 참조 범위

확인 기준일: 2026-11-10. 아래 자료는 날짜와 제한된 사건 맥락을 확인하기 위한 것이다. 실제 게임을 구매·실행하거나 내부 코드를 분석한 결과가 아니다. 참조 게임의 공개 상점 설명과 사용자가 올린 검색 결과 이미지를 기준으로, 동일한 장르의 독자적 구현을 위한 자료를 작성했다.

참조 게임에서 공개적으로 확인한 범위는 1960년 박정희 시점의 시작, 정치·경제 관리, 의회·헌법의 역할, 주요 역사 분기와 복수 엔딩이다. 이 패키지의 월별 수식·이벤트·자문 인물·지도·이미지·엔딩 조건은 자체 설계다. 원작의 전체 데이터나 내부 규칙을 재현했다고 주장하지 않는다.

## 표현 기준

* historical_anchor: 실제 발생한 사건을 한두 문장으로 요약하고 아래 sourceIds를 연결한다. 플레이어의 선택지와 수치 효과는 창작이다.
* fictional_system: 가상 정책 상황. 특정 인물의 실제 발언이나 실제로 있었던 개별 사건이라고 소개하지 않는다.
* 대체역사: 선택 후의 통치 경로·선거 결과·정책 효과는 가상이다. 이미 달라진 정치체제에 실제 사건의 인과관계를 강제로 적용하지 않는다.
* 모든 경제·사회·외교 수치는 모형 값이다. 시작 시점의 물가·실업·생산·지지도가 실제 통계라는 주장은 하지 않는다.
* 1960년부터 대통령 권한을 주지 않는다. 초반은 관찰과 사전 준비다. 군정 경로와 헌정 경로의 권한이 다르다.
* 성장 성과와 인권 침해는 별개의 평가축이다. 경제 성과로 권리 침해를 상쇄하는 단일 도덕 점수를 만들지 않는다.
* 군사정변은 결과와 헌정적 비용만 다룬다. 실제 작전·병력·폭력·은폐의 실행 절차를 구현하지 않는다.
* 노동·민주화 사건의 희생자를 존중한다. 고통을 보상 수단이나 오락용 장면으로 사용하지 않는다.
* 생성 삽화와 가상 자문위원은 실제 역사 사진·실제 관료로 표기하지 않는다.

## 추가 검증이 필요한 영역

실제 GDP·환율·인구·산업 비중·법령 전문·개별 정치인의 발언·당시 지역별 득표는 이 패키지에서 제공하지 않는다. 현실 수치 모드를 추가하려면 한국은행 ECOS·KOSIS·선관위·법령 원문 등으로 계열 정의와 기준연도를 확인해 별도 출처를 붙인다. 검증되지 않은 수치는 기존 가상 지수에 섞지 않는다. 출처 페이지 자체의 날짜 오기나 평가 관점은 다른 기관 자료로 교차 확인한다.
