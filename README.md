## 하루 책상 (`daily/`)

메모, 할 일, 캘린더, 알람, 타이머, 음악, 가계부, 습관, 계산기를 한곳에서 쓰는 개인용 웹사이트입니다.
설치나 서버 없이 `daily/index.html`을 브라우저로 열면 바로 동작하고, 모든 기록은 그 브라우저(localStorage, IndexedDB)에만 저장됩니다.

| 화면 | 할 수 있는 일 |
| --- | --- |
| 홈 | 시계·날짜·음력, 날씨(Open-Meteo), 오늘 할 일, 오늘 일정과 다음 알람, 이번 달 지출, 습관 체크, 디데이, 빠른 메모 |
| 메모 | 자동 저장, 검색, 위에 고정, 색 표시, 공백 포함/제외 글자 수, 내용 복사 |
| 할 일 | 여러 목록, 마감일, 중요 표시, 남은 일/전체/완료 보기, 눌러서 바로 고치기 |
| 캘린더 | 월 보기, 공휴일·대체공휴일 자동 계산(설날·추석·부처님오신날 포함), 음력, 매년 반복 일정 |
| 알람 | 요일 반복, 소리 4종, 5분 뒤 다시 알림, 브라우저 알림 |
| 타이머 | 타이머(라면 3분 같은 프리셋), 스톱워치(랩), 뽀모도로 |
| 음악 | 기기의 음악 파일 재생·보관, 셔플/반복, 시각화, 미니 플레이어, 빗소리·파도·모닥불·백색소음 |
| 가계부 | 수입/지출, 분류별 합계, 한 달 예산과 하루 사용 가능 금액, `점심 9000` 같은 빠른 입력 |
| 습관 | 최근 7일 체크, 연속 기록, 최근 30일 달성률, 5주 기록 |
| 계산기 | 사칙연산(키보드 지원), 더치페이, 단위 변환(평·㎡, 근·g 등) |
| 설정 | 이름, 테마(시스템/밝게/어둡게), 날씨 지역, 기본 알람 소리, 백업 내보내기/불러오기 |

알람과 타이머는 페이지가 열려 있는 동안만 울립니다. 브라우저 정책상 처음 한 번은 화면을 눌러야 소리가 납니다.

- **고백과 연애**: 호감도 50 이상, 이야기 2편을 본 히로인에게는 메인 화면의 「고백하기」로 마음을 전할 수 있습니다(행동치 1). 진심으로 고백하면 연인이 되고, 돌려 말하면 호감도 60 이상일 때만 통하며, 거만하게 밀어붙이면 거절당하고 호감도가 깎입니다. 연인이 되면 「연애」를 행동치 1로 고를 수 있습니다. 학기 중엔 방과 후 산책·도서관 공부 데이트·둘만의 점심과 주말의 시내 데이트·계절 나들이·별 보러 가기 중에서, 방학엔 주말·방학 데이트 중에서 하나를 고르고, 그 자리에서의 행동에 따라 호감도가 +1/+0.3/-1 바뀝니다. 연애 2·5·9회째엔 특별한 장면(처음 잡은 손·둘만의 비밀·미래의 약속)이 있습니다. 연인을 2주 넘게 내버려 두면(-0.6) 서운해하고, 다른 사람과 데이트하면(-1) 소문이 나며, 호감도가 35 아래로 떨어지면 헤어집니다.
- **여름 해변 (☀️)**: 여름방학에 해변(은빛 해변 · 해변 구조대)에 가면 여덟 히로인이 여름 옷(스탠딩·표정·SD·일러스트)으로 나옵니다. 호감도 10 이상인 히로인을 해변에서 만나면 히로인마다 하나씩 「여름 해변 이야기」가 열리고, 여름 일러스트 CG가 나옵니다(파라솔 아래 쉬는 베아트릭스, 수상 추진 보드를 시험하는 로제, 해변 카페에서 백 년 전 일기를 읽는 노엘, 그늘막에서 바람을 맞는 세레나, 꽃 목걸이를 걸어 주는 루나, 노을 속 아리아, 정령을 관측하는 리제트, 수영을 가르쳐 주겠다며 손을 내미는 카밀라). 이야기를 본 뒤엔 프로필에서 「☀️ 여름 의상」으로 여름 그림을 볼 수 있습니다.

  - ❄️ 눈꽃 마을 봉사단(겨울방학·봄방학 · 체력): 젊은이들이 떠난 북쪽 마을에서 촌장 할다와 개 눈송이를 만나, 무너져 가는 분교 지붕의 눈을 치우고, 삼십 년 전 끊긴 「눈꽃 축제」의 기록을 되살려, 얼음 등불 이백 개에 다시 불을 붙입니다.
- **호감도**: 0~100이고, 한 번에 0.1~1씩 오릅니다(소수 첫째 자리까지). 마음을 울린 대답·좋아하는 선물·이야기·첫 데이트는 +1, 좋은 대답 +0.5, 평범한 대답 +0.2, 이미 나눈 이야기를 또 하면 +0.1~0.3, 편지 +0.3입니다. 무심하거나 무례한 대답, 싫어하는 선물, 데이트 중의 나쁜 행동은 호감도를 깎습니다. 히로인은 자주 가는 곳이 있지만 가도 10~30% 확률로만 만날 수 있습니다(날씨에 따라 달라짐). 장소 버튼의 얼굴은 「자주 오는 사람」입니다.
- **주인공 성장**: 총 능력치에 따라 학원 평가 등급(F~S)이 오르고 장학금을 받습니다. 주인공 이야기 「무색의 빛」 9장(라이벌 레온 아드라와 학원장이 등장. 1~5장에서 무색 마법을 익히고, 6·7장은 꺼져 가는 별등의 불씨를 지키는 이야기, 8·9장은 잿빛의 오르반을 쫓아 새 무색 마법 「빛 좇기」(마주칠 확률 +5%)와 「별의 맹세」(판정 +1)를 익히는 이야기)을 진행하면 무색 마법을 익히고, 능력치가 8을 넘으면 특기가 생깁니다(모두 11종). 무색 마법을 하나 각성할 때마다 「별의 탑」에서 한 번 수련할 수 있습니다(모든 능력치 +0.4). 동아리(마도 연구회·검술부·탐험부·성가·연극부)는 매주 활동합니다. 메인 화면의 🌟성장 버튼에서 시간표, 다가오는 행사, 진행 상황을 확인하세요.
- **돌발 사건**: 장소마다 일어나는 사건 33종. 〔용기 5〕처럼 조건이 붙은 선택지는 능력치 판정이고, 조건을 넘으면 ✓가 붙습니다. 조건이 높은 사건일수록 늦게 나옵니다.
- **엔딩 15종**: 히로인 엔딩 8개, 히든 히로인 엔딩 4개(연인이면 축제에서 가장 먼저 그녀에게 갈 수 있음), 노멀 엔딩, 무색의 빛 9장을 마쳤을 때 열리는 성장 엔딩 「나만의 색」, 그리고 여덟 명 모두와 가까워지고(호감도 25 이상) 9장까지 마쳤을 때 열리는 트루 엔딩 「아홉 번째 빛」.
- **연출**: 화자별 이름표 색, 표정에 따른 캐릭터 움직임, 화면 흔들림·섬광·암전, 별·먼지빛·꽃잎·비·눈·불꽃놀이 파티클, 엔딩 크레딧.
- **편의 기능**: 대사 기록(LOG), 자동 진행(AUTO), 빨리 넘기기(SKIP), 대사창 숨기기, 저장 슬롯 3개 + 자동 저장, 앨범(히로인 · 회상 · 엔딩 목록 · 음악감상).
- **음악**: 음원 파일 없이 Web Audio API로 실시간 합성하는 자작곡 10곡(타이틀, 일상, 오후, 연애, 슬픔, 별등, 유적, 길드 거리, 별빛 왈츠, 엔딩)과 효과음. 악보는 `luminaria/js/audio.js`에 있습니다.
- **에셋**: 여름 의상 그림은 여름 캐릭터 시트를 같은 모델로 회전·반전 8방향으로 키워 평균 낸 뒤(뭉개짐 방지), 원본과 어긋난 만큼 되돌려 잔 디테일을 살리고(역투영) 4배 크기 그대로(일러스트·스탠딩 2100px) 저장했습니다(`tools/luminaria_summer.py`). 캐릭터 시트를 Real-ESRGAN(realesr-general-x4v3, 잡음 제거 0.2)으로 4배 키운 뒤 잘라 쓴 키 아트, 배경을 지운 스탠딩(isnet-anime), 표정 6종, SD 캐릭터입니다. 애니 전용 모델(anime 6B)은 머리카락과 눈의 붓 질감을 뭉개서 범용 모델로 바꿨습니다. `python3 tools/luminaria_hd.py <시트 폴더> <모델 폴더> [이름…]`으로 다시 만들 수 있습니다(모델 폴더에 realesr-general-x4v3.pth, realesr-general-wdn-x4v3.pth, isnet-anime.onnx · torch·onnxruntime·scipy 필요). UI 아이콘은 Lucide(ISC 라이선스) 선 아이콘으로 `python3 tools/luminaria_icons.py`가 `luminaria/js/icons.js`를 만들고, 앱 아이콘은 `python3 tools/luminaria_appicon.py`로 그립니다. 배경은 Wikimedia Commons의 퍼블릭 도메인(한 점은 CC BY 4.0, Wellcome Collection) 명화로, `python3 tools/luminaria_bg.py`가 내려받아 2400×1500으로 다듬고(Wikimedia의 표준 1920px 판을 받고, 환경 변수 `LUMI_SR`에 realesr-general-x4v3.pth 경로를 주면 작은 원본을 붓 질감을 살려 AI로 키움) 출처를 `luminaria/img/CREDITS.json`과 게임 안 크레딧에 기록합니다. 2학년 장면용 배경 4점(피사로 「꽃 핀 과수원」, 브뤼헐 「눈 속의 사냥꾼」, 처치 「오로라」, 카유보트 「비 오는 날의 파리 거리」)은 `python3 tools/luminaria_bg.py <캐시> blossom north aurora rain`처럼 이름을 주어 따로 만들 수 있습니다.
