## 하루 책상 (`daily/`)

아침 루틴부터 잠 모드까지 하루를 한곳에서 보내는 개인용 웹사이트입니다. 휴대폰에서는 홈 화면에 추가해 앱처럼 쓸 수 있습니다(PWA).
공개 주소: https://dongjin100621-sketch.github.io/-/ (GitHub Pages가 `docs/`를 배포합니다. `daily/`를 고친 뒤 `docs/`로 복사하고 `sw.js`의 VERSION을 올리세요.)
설치나 서버 없이 `daily/index.html`을 브라우저로 열면 바로 동작하고, 모든 기록은 그 브라우저(localStorage, IndexedDB)에만 저장됩니다.

| 화면 | 할 수 있는 일 |
| --- | --- |
| 홈 | 시계·날짜·음력, 날씨(Open-Meteo), 지금 루틴, 물·약, 하루 마무리(기분·일기·잠 모드), 오늘 할 일, 오늘 일정과 다음 알람, 이번 달 지출, 습관, 디데이, 빠른 메모. 시간대(아침/낮/밤)에 따라 카드 순서가 바뀜 |
| 루틴 | 아침·저녁 체크리스트(날마다 새로 시작), 단계별 타이머로 따라 하기, 최근 7일 기록 |
| 일기 | 하루 한 장: 기분 5단계, 오늘의 질문, 감사한 일 세 가지, 그날 한 일 자동 요약, 기분 달력, 검색 |
| 건강 | 물(목표·알림), 식사와 "오늘 뭐 먹지?" 메뉴 추천, 운동, 약·영양제 시간 알림, 체중 그래프, 수면 요약 |
| 잠 | 잠 모드(어두운 시계, 화면 꺼짐 방지, 소리·수면 타이머, 알람을 끄면 수면 기록과 아침 브리핑), 잘 시간 계산기, 취침 알림, 호흡, 수면 기록 |
| 찾기 | Ctrl+K / ⌘K / `/` 로 메모·할 일·일정·일기·지출·루틴을 한 번에 찾기 |
| 메모 | 자동 저장, 검색, 위에 고정, 색 표시, 공백 포함/제외 글자 수, 내용 복사 |
| 할 일 | 여러 목록, 마감일, 중요 표시, 남은 일/전체/완료 보기, 눌러서 바로 고치기 |
| 캘린더 | 월 보기, 공휴일·대체공휴일 자동 계산(설날·추석·부처님오신날 포함), 음력, 매년 반복 일정 |
| 알람 | 요일 반복, 소리 4종, 5분 뒤 다시 알림, 브라우저 알림 |
| 타이머 | 타이머(라면 3분 같은 프리셋), 스톱워치(랩), 뽀모도로 |
| 음악 | 기기의 음악 파일 재생·보관, 셔플/반복, 시각화, 미니 플레이어, 빗소리·파도·모닥불·백색소음, 31밴드 이퀄라이저, 헤드폰 모드 |
| 가계부 | 수입/지출, 분류별 합계, 한 달 예산과 하루 사용 가능 금액, `점심 9000` 같은 빠른 입력 |
| 습관 | 최근 7일 체크, 연속 기록, 최근 30일 달성률, 5주 기록 |
| 계산기 | 사칙연산(키보드 지원), 더치페이, 단위 변환(평·㎡, 근·g 등) |
| 설정 | 이름, 테마, 날씨 지역, 기본 알람 소리, 화면 켜 두기, 이어폰으로만 알람, 백업 내보내기/불러오기 |

알람과 타이머는 페이지가 열려 있는 동안만 울립니다. 밤에는 잠 모드(화면 꺼짐 방지)를 켜 두세요. 브라우저 정책상 처음 한 번은 화면을 눌러야 소리가 납니다.
