## 하루 책상 (`daily/`)

아침 루틴부터 잠 모드까지 하루를 한곳에서 보내는 개인용 웹사이트입니다. 휴대폰에서는 홈 화면에 추가해 앱처럼 쓸 수 있습니다(PWA).
공개 주소: https://dongjin100621-sketch.github.io/-/ (GitHub Pages가 `docs/`를 배포합니다. `daily/`를 고친 뒤 `docs/`로 복사하고 `sw.js`의 VERSION을 올리세요.)
설치나 서버 없이 `daily/index.html`을 브라우저로 열면 바로 동작하고, 모든 기록은 그 브라우저(localStorage, IndexedDB)에만 저장됩니다.

| 화면 | 할 수 있는 일 |
| --- | --- |
| 홈 | 시계·날짜·음력, 날씨(Open-Meteo), 지금 루틴, 물·약, 하루 마무리(기분·일기·잠 모드), 오늘 할 일, 오늘 일정과 다음 알람, 이번 달 지출, 습관, 디데이, 빠른 메모. 시간대(아침/낮/밤)에 따라 카드 순서가 바뀜 |
| 루틴 | 아침·저녁 체크리스트(날마다 새로 시작), 단계별 타이머로 따라 하기, 최근 7일 기록 |
| 일기 | 하루 한 장: 기분 5단계, 오늘의 질문, 감사한 일 세 가지, 그날 한 일 자동 요약, 기분 달력, 검색 |
| 건강 | 물(목표·알림), 식사와 "오늘 뭐 먹지?" 메뉴 추천, 운동, 약·영양제 시간 알림, 체중 그래프, 수면 요약 |
| 잠 | 잠 모드(어두운 시계, 화면 꺼짐 방지, 소리·수면 타이머, 알람을 끄면 수면 기록과 아침 브리핑), 잘 시간 계산기, 취침 알림, 호흡, 수면 기록 |
| 찾기 | Ctrl+K / ⌘K / `/` 로 메모·할 일·일정·일기·지출·루틴을 한 번에 찾기 |
| 메모 | 자동 저장, 검색, 위에 고정, 색 표시, 공백 포함/제외 글자 수, 내용 복사 |
| 할 일 | 여러 목록, 마감일, 중요 표시, 남은 일/전체/완료 보기, 눌러서 바로 고치기 |
| 캘린더 | 월 보기, 공휴일·대체공휴일 자동 계산(설날·추석·부처님오신날 포함), 음력, 매년 반복 일정 |
| 알람 | 요일 반복, 소리 4종, 5분 뒤 다시 알림, 브라우저 알림 |
| 타이머 | 타이머(라면 3분 같은 프리셋), 스톱워치(랩), 뽀모도로 |
| 음악 | 기기의 음악 파일 재생·보관, 셔플/반복, 시각화, 미니 플레이어, 빗소리·파도·모닥불·백색소음, 31밴드 이퀄라이저, 헤드폰 모드 |
| 가계부 | 수입/지출, 분류별 합계, 한 달 예산과 하루 사용 가능 금액, `점심 9000` 같은 빠른 입력 |
| 습관 | 최근 7일 체크, 연속 기록, 최근 30일 달성률, 5주 기록 |
| 계산기 | 사칙연산(키보드 지원), 더치페이, 단위 변환(평·㎡, 근·g 등) |
| 설정 | 이름, 테마, 날씨 지역, 기본 알람 소리, 화면 켜 두기, 이어폰으로만 알람, 백업 내보내기/불러오기 |

알람과 타이머는 페이지가 열려 있는 동안만 울립니다. 밤에는 잠 모드(화면 꺼짐 방지)를 켜 두세요. 브라우저 정책상 처음 한 번은 화면을 눌러야 소리가 납니다.

## 네온 하트 (`neon/`)

2089년 네오 서울을 배경으로 한 고해상도 도트 횡스크롤 사이버펑크 RPG입니다. 기억을 잃은 소녀 세라와의 사랑 이야기를 따라갑니다.
공개 주소: https://dongjin100621-sketch.github.io/-/neon/ (`neon/`을 고친 뒤 `python3 tools/build_pwa.py neon`으로 `docs/neon/`에 복사하세요.)

| 항목 | 내용 |
| --- | --- |
| 화면 | 1280×800 고정 무대를 화면에 맞춰 확대, 네온 고층 빌딩 배경(4겹 시차 스크롤, 비·안개) |
| 조작 | 왼쪽 조이스틱(위로 밀면 점프), 오른쪽 큰 기본 공격, 그 북서쪽으로 공격 스킬·범용 스킬·필살기, 공격 스킬 왼쪽 아래 아이템 칸. 키보드도 지원 |
| HUD | 왼쪽 위 체력·RAM·경험치 바와 지역 지도, 오른쪽 위 가방·능력·퀘스트·지도·설정 |
| 이야기 | 메인 8장 + 곁가지 7개, 호감도에 따라 결말 3종 |
| 보스 | 중간보스 레드 조·헤일로, 최종보스 오라클 (각 2페이즈) |
| 아이템 | 168종(무기 48·의상 36·사이버웨어 48·소모품 24·선물 12), 초급·중급·고급·기밀 4등급 |
| 성장 | 능력치 5종(신체·반사·기술·지능·침착), 레벨마다 능력치·특성 포인트 → 특성 30종·스킬 15종 해금 |

캐릭터 그림은 `tools/neon_src/`의 시트에서 `tools/neon_sprites.py`로 잘라 `neon/img/sprites.png`를 만듭니다. 글을 고친 뒤에는 `tools/neon_font.py`로 글꼴을 다시 줄이세요.

## 은빛 유랑기 (`wander/`)

중세 판타지 대륙 에이렌의 중앙·북부·남부·서부·동부를 유람하는 텍스트 기반 TRPG입니다. 은빛 머리와 푸른 눈의 여행자가 마른 청령화를 피우기 위해 다섯 지역의 재앙을 걷어 내고 꽃잎(유람 인장)을 모읍니다.
공개 주소: https://dongjin100621-sketch.github.io/-/wander/ (`wander/`를 고친 뒤 `python3 tools/build_pwa.py wander`로 `docs/wander/`에 복사하세요.)

| 항목 | 내용 |
| --- | --- |
| 판정 | d20 + 능력치 보정 ≥ DC (20 대성공, 1 대실패). 선택지마다 DC·보정·성공 확률 표시 |
| 직업 | 검사·순찰자·마법사·음유시인. 능력치 5종(힘·민첩·지능·매력·체질), 직업 특성, 레벨별 기술 |
| 지역 | 중앙 왕도 루멘하르트, 서부 엘름우드, 남부 사하렌, 동부 연화성, 북부 하르그림. 지역마다 탐험 사건·상점·여관·의뢰 게시판 |
| 이야기 | 지역별 3장짜리 메인 퀘스트와 보스 5종, 다섯 인장을 모으면 열리는 최종장과 결말 |
| 전투 | 턴제(공격·기술·아이템·도주), 독·둔화·강공 예고·흡혈·재생 등 적 특수 능력, 연막탄·룬 숫돌 같은 전투 도구 |
| 상태창 | 데스크톱은 오른쪽 고정 패널, 휴대폰은 위쪽 요약 막대 + 아래에서 올라오는 시트. 탭: 상태(초상·체력·능력치·장비·기술·인장)·가방·임무·지도·일지 |
| 곁이야기 | 12개: 지역별 사이드 퀘스트 + 견습 기사·엘프 무덤·검투장·백 년의 바둑·마지막 사냥·해골섬·재 속의 대장장이 |
| 즐길 거리 | 탐험 사건 지역당 8종, 길 위 사건 10종, 여관 주사위 내기, 몬스터 도감(일지 탭) |
| 세계 | 8개 지역: 기존 5곳 + 산호 군도·잿빛 황무지·천공섬 아스트라(최종장 1부를 마치면 열림) |
| 메인 이야기 | 지역 이야기 5개 + 중앙 2부「왕도의 그림자」·군도「심해의 종」·황무지「재의 왕관」 + 최종장 1·2부. 기억 조각 3개를 모으면 진 결말 |
| 전직 | 레벨 6에 왕도 영웅의 전당에서 시험 → 직업마다 2갈래(성기사·광전사 / 저격수·야수지기 / 원소술사·시간술사 / 검무가·성가대장) |
| 스킬 트리 | 레벨마다 기술 포인트 1. 직업 트리 8칸 + 전직 트리 3칸(선행 조건·레벨 조건) |
| 장비·룬 | 투구 칸 추가, 장비 등급 5단계(일반~전설)와 홈 0~3개. 룬 14종을 무기·방어구 칸에 새기고, 세 룬 조합으로 룬어 6종 |
| 디자인 | Claude 팔레트(미색 종이·먹색 + 테라코타 강조). 밝게·어둡게·자동(기기 설정) 테마 |
| 저장 | 브라우저 localStorage에 자동 저장 (전투 도중에 닫으면 마을에서 다시 시작) |
