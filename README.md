## 하루 책상 (`daily/`)

메모, 할 일, 캘린더, 알람, 타이머, 음악, 가계부, 습관, 계산기를 한곳에서 쓰는 개인용 웹사이트입니다.
설치나 서버 없이 `daily/index.html`을 브라우저로 열면 바로 동작하고, 모든 기록은 그 브라우저(localStorage, IndexedDB)에만 저장됩니다.

| 화면 | 할 수 있는 일 |
| --- | --- |
| 홈 | 시계·날짜·음력, 날씨(Open-Meteo), 오늘 할 일, 오늘 일정과 다음 알람, 이번 달 지출, 습관 체크, 디데이, 빠른 메모 |
| 메모 | 자동 저장, 검색, 위에 고정, 색 표시, 공백 포함/제외 글자 수, 내용 복사 |
| 할 일 | 여러 목록, 마감일, 중요 표시, 남은 일/전체/완료 보기, 눌러서 바로 고치기 |
| 캘린더 | 월 보기, 공휴일·대체공휴일 자동 계산(설날·추석·부처님오신날 포함), 음력, 매년 반복 일정 |
| 알람 | 요일 반복, 소리 4종, 5분 뒤 다시 알림, 브라우저 알림 |
| 타이머 | 타이머(라면 3분 같은 프리셋), 스톱워치(랩), 뽀모도로 |
| 음악 | 기기의 음악 파일 재생·보관, 셔플/반복, 시각화, 미니 플레이어, 빗소리·파도·모닥불·백색소음 |
| 가계부 | 수입/지출, 분류별 합계, 한 달 예산과 하루 사용 가능 금액, `점심 9000` 같은 빠른 입력 |
| 습관 | 최근 7일 체크, 연속 기록, 최근 30일 달성률, 5주 기록 |
| 계산기 | 사칙연산(키보드 지원), 더치페이, 단위 변환(평·㎡, 근·g 등) |
| 설정 | 이름, 테마(시스템/밝게/어둡게), 날씨 지역, 기본 알람 소리, 백업 내보내기/불러오기 |

알람과 타이머는 페이지가 열려 있는 동안만 울립니다. 브라우저 정책상 처음 한 번은 화면을 눌러야 소리가 납니다.

## 루미나리아: Eight Fates (`luminaria/`)

마법 학원을 배경으로 한 미소녀 연애 시뮬레이션입니다. `luminaria/index.html`을 브라우저로 열면 바로 플레이할 수 있고, 진행 상황은 브라우저(localStorage)에 자동 저장됩니다.

- **줄거리**: 어느 속성으로도 분류되지 않는 「무색」의 마력을 가진 주인공이 특별 청강생으로 루미나리아 아카데미에 입학합니다. 천 년 동안 타오른 「별등」이 흔들리는 가운데, 4월 24일 별빛 축제까지 남은 시간을 누구와 보낼지 고릅니다.
- **히로인 8명**: 세레나, 루나, 카밀라, 아리아, 리제트, 로제, 노엘, 베아트릭스. 히로인마다 첫 만남, 일상 대화 8종, 개별 이야기 3편, 주말 데이트, 축제 전야, 엔딩이 있습니다.
- **공통 이벤트**: 입학 환영회(4일), 중간 시험(8일, 지력에 따라 결과가 달라짐), 흔들리는 별등(12일), 유적 합동 실습(16일, 함께 싸울 히로인 선택), 축제 준비 위원회(20일), 축제 전야(23일).
- **엔딩 10종**: 히로인 엔딩 8개, 노멀 엔딩, 그리고 여덟 명 모두와 가까워졌을 때 열리는 트루 엔딩 「아홉 번째 빛」.
- **진행 방식**: 하루는 오전·오후로 나뉩니다. 수업, 도서관, 훈련, 탐험, 공방, 성당, 상점가, 휴식 중 한 곳을 골라 능력치(지력·체력·용기·매력)를 올리고, 그곳에 있는 히로인과 이야기하세요. 날씨(맑음·흐림·비)에 따라 히로인이 있는 곳이 달라지고, 주말에는 데이트를 신청할 수 있습니다.
- **연출**: 화자별 이름표 색, 표정에 따른 캐릭터 움직임, 화면 흔들림·섬광·암전, 별·먼지빛·꽃잎·비·불꽃놀이 파티클, 엔딩 크레딧.
- **편의 기능**: 대사 기록(LOG), 자동 진행(AUTO), 빨리 넘기기(SKIP), 대사창 숨기기, 저장 슬롯 3개 + 자동 저장, 앨범(히로인 · 회상 · 엔딩 목록 · 음악감상).
- **음악**: 음원 파일 없이 Web Audio API로 실시간 합성하는 자작곡 10곡(타이틀, 일상, 오후, 연애, 슬픔, 별등, 유적, 길드 거리, 별빛 왈츠, 엔딩)과 효과음. 악보는 `luminaria/js/audio.js`에 있습니다.
- **에셋**: 캐릭터 시트에서 잘라낸 키 아트, 표정 6종, SD 캐릭터를 씁니다. `python3 tools/luminaria_assets.py <시트 폴더> luminaria/img`로 다시 만들 수 있습니다. 배경은 Wikimedia Commons의 퍼블릭 도메인(한 점은 CC BY 4.0, Wellcome Collection) 명화로, `python3 tools/luminaria_bg.py`가 내려받아 다듬고 출처를 `luminaria/img/CREDITS.json`과 게임 안 크레딧에 기록합니다.

**플레이 주소**: https://dongjin100621-sketch.github.io/-/luminaria/

**아이폰·아이패드(사파리)에 앱처럼 설치하기**: 사파리로 위 주소를 연 뒤 공유 버튼(□↑) → 「홈 화면에 추가」를 누르세요. 홈 화면 아이콘으로 열면 주소창 없이 전체 화면으로 실행되고, 한 번 열어 두면 오프라인에서도 플레이할 수 있습니다.

게임 파일(`luminaria/`)을 고친 뒤에는 `python3 tools/build_pwa.py`를 실행하세요. 서비스 워커의 파일 목록과 버전을 갱신하고, GitHub Pages 배포용 `docs/luminaria/`로 복사합니다.
