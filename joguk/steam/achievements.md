# Steam 업적 목록

Steamworks 관리 화면 → **통계 및 업적 → 업적**에서 아래 API 이름 그대로 만들면, 게임 안에서 업적을 달성할 때 Steam 업적도 함께 열립니다.
(게임 코드: `js/story.js`의 `ACHIEVEMENTS`, 연동: `electron/main.js`)

| API 이름 | 표시 이름 | 설명 |
| --- | --- | --- |
| `ACH_FIRST_END` | 첫 번째 결말 | 엔딩을 하나 보았다. |
| `ACH_HISTORY` | 역사의 길 | ‘10·26’ 엔딩에 도달했다. |
| `ACH_IFS` | 만약에 | 역사와 다른 엔딩을 5개 보았다. |
| `ACH_ALL_END` | 모든 갈래 | 12개의 엔딩을 모두 보았다. |
| `ACH_HIGHWAY` | 2년 5개월 | 경부고속도로를 29개월 안에 완공했다. |
| `ACH_SAFE` | 위령탑 없는 길 | 순직자 없이 경부고속도로를 완공했다. |
| `ACH_EXPORT` | 100억 달러 | 수출 미니게임에서 목표를 달성했다. |
| `ACH_NO_OT` | 일요일은 쉬게 하라 | 잔업 없이 수출 목표를 달성했다. |
| `ACH_ARCHIVE` | 기록 보관소 | 모든 역사 기록을 열람했다. |

업적 아이콘(64×64 JPG, 달성/미달성 2종)은 Steamworks에 따로 올려야 합니다.
