    내 곡

      도움말

      음표 넣기

      • 그리기 도구로 빈 칸을 누르면 음표가 생기고, 누른 채 오른쪽으로 끌면 길어집니다. 음표를 끌면 옮겨지고, 오른쪽 끝을 끌면 길이가 바뀝니다.
      • 음표를 두 번 누르거나 오른쪽 클릭하면 지워집니다. 지우기 도구로 문질러도 됩니다.
      • 선택 도구로 빈 곳을 끌면 여러 음표를 고릅니다(그리기 도구에서는 Shift+끌기). Alt+끌기는 복사해서 옮깁니다.
      • 드럼 트랙에서는 칸을 누를 때마다 켜고 끄며, 끌면 여러 칸을 한 번에 칠합니다.
      • 위쪽 코드 줄을 누르면 그 마디의 코드를 고릅니다. 자동 작곡에서 "코드 줄 그대로"를 고르면 직접 쓴 진행으로 반주를 만듭니다.
      • 위쪽 마디 자를 누르면 재생 위치가 옮겨지고, 끌면 반복 구간이 정해집니다.

      화면 움직이기

      • 휠: 위아래 · Shift+휠: 좌우 · Ctrl+휠: 가로 확대 · Alt+휠: 세로 확대
      • 휴대폰·태블릿: 두 손가락으로 끌면 이동, 벌리면 확대. 한 손가락 이동은 화면 이동 도구.

      연주와 녹음

      • 아래 건반을 누르거나, "컴퓨터 키보드로 연주"를 켜고 A~;(흰건반)·W E T Y U O P(검은건반)를 누릅니다. Z/X는 옥타브.
      • 녹음을 켜고 재생하면 연주가 그대로 기록되고, 멈춘 채로 녹음을 켜면 누를 때마다 격자 한 칸씩 음이 들어갑니다(화음은 함께 누르기).
      • MIDI 건반은 파일·설정 → MIDI 건반 연결(크롬·엣지).

      단축키

      • 드럼 트랙: A~' 순서로 킥·스네어·클랩·하이햇·탐·심벌·탬버린·셰이커
      • 스페이스 재생/멈춤 · Home 처음으로 · 1~4 도구
      • Ctrl+Z 되돌리기 · Ctrl+Shift+Z/Ctrl+Y 다시 · Ctrl+A/C/X/V/D 전체선택/복사/잘라내기/붙여넣기/복제
      • ↑↓ 반음(Shift는 옥타브) · ←→ 격자 한 칸 · Del 지우기 · Esc 선택 풀기

      박자는 4/4 고정입니다. 소리는 모두 브라우저 안에서 합성하며(샘플 파일 없음), 페이지를 처음 누른 뒤부터 납니다.

      믹서

      트랙마다 앰프 → EQ → 컴프 → 음량·팬 순서로 지나가고, 리버브·딜레이로 보냅니다. 재생하면서 바꿔 보세요.
