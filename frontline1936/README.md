# 전선과 공장: 동아시아 1936

1936년 1월 1일부터 1945년 12월 31일까지, 동아시아와 태평양을 무대로 하루씩 흐르는 대전략 게임입니다. 일본·중화민국(국민정부)·중국 공산당·소련·미국·영국 가운데 한 나라를 골라 국가 중점으로 나라의 길을 정하고, 공장을 지어 장비를 만들고, 사단을 설계해 전선을 지킵니다. 나머지 나라(만주국·군벌·시암·프랑스·네덜란드·오스트레일리아 등 18개국)는 컴퓨터가 움직입니다.

잘 알려진 대전략 게임의 **장르 구조**(국가 중점 나무, 정치력과 법, 연구 칸, 사단 설계, 전선과 전투 폭, 생산 라인과 효율, 해상 우세와 상륙, 항공 구역)를 참고해 새로 만들었습니다. 이름·지도·화면·문구·수치·코드는 이 게임의 것이며 원작의 자료를 쓰지 않았습니다. **산업은 《대한민국 1960》의 시장 경제 엔진**(구매·판매 주문으로 정해지는 가격, 생산방식이 있는 건물, 충원율과 임금, 계층 소득과 가계 수요, 건설점과 대기열, 세계시장 교역)을 나라마다 따로 돌리도록 넓혀 썼습니다.

## 실행

* `FRONTLINE1936.html`을 브라우저에서 엽니다(더블클릭). 설치·서버·로그인·외부 요청이 없습니다.
* 개발: 저장소 루트에서 `python3 -m http.server` 뒤 `frontline1936/game/index.html`을 엽니다(분리 소스를 그대로 읽음).
* 자동 저장은 그 브라우저에만 남습니다. 기록 창에서 저장 텍스트를 복사하거나 파일로 내려받아 옮길 수 있습니다.

## 조작

* 시간: 위의 Ⅱ(멈춤)와 1~5(속도). 키보드 스페이스·1~5. 결정할 사건이 오면 멈춥니다.
* 지도: 끌어서 이동, 휠·두 손가락으로 확대. 지역을 누르면 정보·건설, 우리 사단 표를 누르면 사단 선택.
* 사단을 고른 채 지역을 누르면 명령: 우리 땅은 이동(바다 건너는 길도 자동), 맞닿은 적 지역은 공격, 바다 건너 적 해안은 상륙.
* 함대를 고른 채 해역이나 아군 항구를 누르면 이동. 비행단은 '작전 구역 고르기' 뒤 지도를 누릅니다.

## 역사와 창작의 구분

* 사건의 '실제 역사' 문단만 사실이며, 수치·선택 결과·AI의 전개는 게임을 위한 창작입니다.
* 정치 폭력과 전쟁 범죄는 절차를 재현하지 않고 제도적 결과만 다룹니다. 민간인 피해·강제 동원을 게임의 보상으로 쓰지 않습니다. 핵무기는 다루지 않습니다.
* 깃발 대신 단색을 씁니다.
* 지도는 Natural Earth 1:10m(퍼블릭 도메인)에서 `tools/make_map.py`로 만들었습니다. 지역 경계는 1936년의 실제 경계가 아닌 근사입니다(러허·차하르·쑤이위안 등은 점으로 나눔).
* 글꼴: Noto Sans KR·Noto Serif KR(제목, SIL OFL 1.1) 서브셋. 그림은 모두 SVG로 직접 그렸고 사진·외부 이미지를 쓰지 않았다(장군도 이름 첫 글자 표지만 쓴다).

## 개발

| 경로 | 내용 |
| --- | --- |
| `data/src/*.mjs` | 콘텐츠의 원본: 지역 표, 나라, 규칙(상품·건물·장비·대대·편제·함선·기술·법·국가 정신·경제 상수·날씨·기후대), 장군·제독, 국가 중점, 사건 |
| `data/game.json` | `node tools/build_data.mjs`가 만든 실행용 데이터(검사 포함) |
| `data/map.json` | 지도(경로·인접·해안·경계선) |
| `game/core.mjs` | 날짜·난수·색인·나라별 보정값·관계 |
| `game/economy.mjs` | 나라별 시장 경제·생산 라인·조선·건설 |
| `game/military.mjs` | 사단 능력치·경로·전투·점령·보급·항공·해군·장군과 군 |
| `game/weather.mjs` | 기후대와 하루 날씨 |
| `game/politics.mjs` | 효과·전쟁과 강화·사건·국가 중점·연구·법·항복 |
| `game/ai.mjs` | 컴퓨터 나라의 경제·연구·중점·모집·전선·상륙·해군·공군 판단 |
| `game/engine.mjs` | 새 게임, 행동(dispatch), 하루 진행, 저장 |
| `game/app.mjs`, `game/style.css` | 화면 |

```
node tools/build_data.mjs          # data/src → data/game.json (+ 검사)
npm test                           # 엔진 테스트 18개(10년 자동 진행 포함, 약 1분 반)
python3 tools/build_standalone.py  # FRONTLINE1936.html
node tests/browser/e2e.cjs         # 브라우저 검수(Playwright 필요)
```

## 알려진 한계 (0.2.0)

* 첫 판입니다. 원작급 규모(수천 개의 주, 수십 개국의 고유 콘텐츠, 장교·정보·저항 체계)를 모두 구현했다고 하지 않습니다. 고유 국가 중점은 주요국 6개뿐이고, 사단 장비의 세대는 나라의 최신 기술로 일괄 계산합니다.
* AI 밸런스는 자동 진행으로만 맞췄습니다. 판(난수 씨앗)마다 전개가 크게 다릅니다. 시험한 씨앗 넷 가운데 둘은 일본이 1939년까지 중국 동부 대부분을 차지했고, 하나는 화북에서 교착했습니다. 한 씨앗의 10년 진행에서는 일본이 1941년 말 정점에 이른 뒤 1942년부터 미국의 섬 공략으로 밀리다 1945년에 크게 무너졌습니다. 일본의 남방 공략은 실제보다 좁고, 베이핑처럼 방어 사단이 몰린 도시는 오래 버팁니다. 국민정부는 승점의 88%를 잃어야 항복합니다.
* 미국·영국·오스트레일리아 AI는 1945년 3월 전에는 대륙과 일본 본토에 상륙하지 않습니다(징검다리 규칙).
* 경제 수치는 실제 통계가 아닌 게임 단위입니다. 야간·강·철도 노선·전투 사기는 없습니다. 날씨는 기후대의 확률로 만든 가상 날씨이며 실제 기상 기록이 아닙니다. 장군 능력치는 게임 설계값입니다.
* 컴퓨터 나라는 매달 군을 다시 짜서 장군을 붙입니다. 플레이어의 나라도 처음에는 컴퓨터가 군과 장군을 짜 둡니다(바꿀 수 있습니다).
* 사람이 직접 한 플레이테스트, 실제 Windows·Safari·iOS 확인은 하지 않았습니다.
